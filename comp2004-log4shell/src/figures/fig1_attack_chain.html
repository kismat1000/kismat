1

Crafted input

Attacker places a ${jndi:…} lookup string in any field the application logs (HTTP header, form field, username, chat message).

2

Log4j logs it

Application logs the input with a vulnerable Log4j 2 version (2.0-beta9 to 2.15.0). Lookup substitution evaluates the embedded expression.

3

Outbound JNDI lookup

The server itself opens an outbound LDAP, RMI or DNS connection to a host named by the attacker.

4

Malicious reference

Attacker-controlled directory server returns a reference pointing to a remote Java class.

5

Remote code execution

The JVM loads and runs the class with the application's privileges: shells, miners, ransomware, backdoors.
